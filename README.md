# DiscoNER

An interactive web tool for annotating **discontinuous named entities**, built for COM S 5790 (Natural Language Processing), Iowa State University, Fall 2026.

**Live app:** https://saiujwalveerapalli.github.io/DiscoNER/

## Features
- In-text display of discontinuous entities (fragments linked by arcs) and overlapping entities
- Mouse-only annotation: create entities, add fragments, change type, delete
- Multiple entity types (CADEC: ADR, Drug, Disease, Symptom, Finding) plus custom types
- Open .txt, .json, or a CADEC/BRAT .txt + .ann pair
- Download annotations as JSON or BRAT .ann
- Undo/redo

## Usage
Open the live app (or index.html locally), click **Open file**, annotate, and download.
